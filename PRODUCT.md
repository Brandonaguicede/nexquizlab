# NexQuiz
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
React, TypeScript, Vite, Tailwind CSS, React Router, Lucide; NestJS, PostgreSQL, Prisma. Selected explicitly by the project brief.
## Users
Teachers prepare true/false evaluations; students will join real-time sessions on different devices.
## Product Purpose
An autonomous platform for interactive assessments, with independently consumable APIs. Final project EIF400; Hito 1 foundation and Hito 2 independent identity.
## Capabilities and Constraints
The foundation provides architecture, persistence, observability, deployment definitions and service health. Hito 2 adds registration, login, profile, session renewal/logout and independent Game identity verification. Quizzes, rooms, roles and scoring remain deferred. Game server will be authoritative.
## Brand Commitments
NexQuiz — Learn. Play. Identity brief ends at this phrase; remaining brand details are unspecified.
## Open Decisions
Initial screen assumed to be a sober teacher-facing start with service status and documentation, after an optional question without response. This is a reversible implementation choice.
