# Hito 1 — NexQuiz foundation
## Why
Create independent APIs and a production-oriented architecture before adding identity and gameplay behavior.
## What Changes
Introduce pnpm workspaces, React shell, NestJS layers, private Prisma clients and migrations, isolated PostgreSQL databases, service health, OpenAPI/Scalar, OTLP metrics/traces, Docker and deployment documentation.
## Capabilities
- platform-foundation
## Impact
New repository. No existing behavior is migrated. Registration, login, JWT issuance, quiz CRUD, Socket.IO gameplay and scores are explicitly excluded.
